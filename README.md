# Sistem Informasi Toko Delima

Sistem Informasi Toko Delima adalah aplikasi untuk membantu mengelola barang, persediaan, pembelian, dan transaksi penjualan toko. Aplikasi ini digunakan oleh pemilik, supervisor, dan kasir sesuai tugas masing-masing.

## Fitur utama

- Mengelola data barang dan supplier.
- Mencatat pembelian dan memperbarui stok secara otomatis.
- Melayani transaksi kasir untuk pembayaran tunai atau transfer.
- Menampilkan struk, kartu stok, dan laporan sesuai hak akses pengguna.

## Hak akses pengguna

- **Owner** dapat mengakses seluruh menu, termasuk laporan pembelian dan penjualan.
- **Supervisor** dapat mengelola barang, supplier, pembelian, dan informasi stok.
- **Kasir** dapat melakukan transaksi penjualan dan melihat struk.

## Mulai menggunakan aplikasi

Jika aplikasi sudah disediakan secara online, buka alamat website yang diberikan oleh pengelola toko dan masuk menggunakan akun Anda. Hubungi pengelola jika belum memiliki akun atau mengalami kendala akses.

Untuk menjalankan demo di komputer Windows, melihat akun demo, dan mengikuti alur presentasi, buka [Panduan Demo Website](./PANDUAN-DEMO.md).

## Catatan

Data yang disediakan untuk demo adalah data contoh, bukan data Toko Delima yang sebenarnya. Pada versi ini, transaksi yang sudah tersimpan tidak dapat diedit atau dibatalkan; fitur retur belum tersedia.

Pengelola teknis dapat melihat [Panduan Deployment](./PANDUAN-DEPLOYMENT.md).
